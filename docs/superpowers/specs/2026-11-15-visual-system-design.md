# 前端视觉与交互系统升级（precision instrument）

用户方向（2026-11-15）：当前前端样式太丑，希望达到优秀网页水准，包括交互组件。定位为工具型产品界面的系统性升级，不改变任何功能与信息架构。

## 设计方向

"精密仪器"：微暖中性画布、墨色优先的层级、单一克制的蓝色强调（仅动作/激活/链接）、语义状态统一为药丸语言、两层海拔（1px 边框 + 极轻分层阴影）、6/8/12 圆角阶（控件 8、容器 12、药丸全圆）、140ms 动效层（悬停/按压/焦点）并在 `prefers-reduced-motion` 下全部静止。基准是 figma.com / x.ai 一级工具产品的完成度。

## 实现

- **theme.tsx 重写**（令牌唯一来源，运行时覆盖旧 CSS 变量）：精调浅/深双模式色板（微暖中性 rail/surface、更深一档的按钮悬停色取代 `filter: brightness`、AA 级对比的正文/次级文本）、MUI 组件默认值全面接管——按钮（140ms 过渡、按压 0.985 缩放、焦点双环）、输入框（8px 圆角、聚焦 3px 柔和环）、对话框/抽屉/菜单（12/0/10px 圆角、1px 边框 + 分层阴影）、选项卡（2px 强调色指示条）、药丸形 Chip、深浅自适应 Tooltip、菜单项过渡。
- **新增 system.css 精修层**（最后加载）：动效层（按钮/卡片/行/导航对指针的即时回应）、卡片悬停上浮 1px + 阴影升级（取代仅变色）、行悬停节奏与表格数字等宽对齐、状态药丸语言（`.pill-*` 语义族 + 既有状态面迁移）、侧栏结构（分组标签 11px/620/0.05em、激活项内嵌 2px 强调条）、统一标题展示阶、空状态虚线容器、细滚动条、选区色、reduced-motion 全静止。
- **旧 CSS 热点就地修改**：三处不一致的页面标题（27/26/24px 混用）统一为 24px/650/-0.02em；导航分组标签与搜索框圆角对齐。

## 验证与边界

- 本环境无法逐像素目检（截图工具返回不可渲染），验证手段为：构建产物检查（新层在包内）、真实浏览器计算样式核对（标题/圆角/过渡/色板逐项命中）、axe-core 审计（首页与工作区视图均 **0 违规**，各 1 处 placeholder/aria 需人工复核项，已在报告说明）、前端 56 测试全过 + 生产构建。截图五张存档（首页/工作区/标准库 × 深浅）供人工复核。
- 4400 行旧 CSS 未整体重写（两文件并存历史），采用"令牌统一 + 主题层接管 + 精修层覆盖 + 热点就地改"的分层策略；后续页面级改版可逐步把旧规则迁入 system.css。
- 未引入新依赖；深浅模式切换、可访问性语义、全部交互行为保持不变。
