## 3. 两类合成任务与阻塞边界

### 已完成的命令/文件任务

- **本地沙盒**：同一输入在 `local_command` 下产生通过、业务失败（错误预期）、缺失证据（`validation_error`，分数未知）、超时（`execution_error`）。沙盒拒绝写出单题目录、拒绝网络连接；证据目录与逐题输出保留。
- **Harbor 容器**：`harbor` 环境准备后，两题在容器内真实执行 `python3 main.py`；通过题为 `passed` 并回收 `report.json` 与容器元数据，错误预期题为 `failed`（score 0）；零模型调用、金额未知。
- **HTTP**：只接受 loopback 目标并要求显式确认独立测试数据；本机合成目标返回 `sum=5`，题目 `passed`。

### 未完成的对话任务（阻塞，不宣称通过）

对话题目已创建并版本化（脚本两轮输入、来源与未知项），但执行要求 `aigateway_go` 适配器与真实目标模型；本机没有授权端点，因此：

- 用本地命令执行器预检对话题目返回 `422 task_adapter_mismatch`，不会静默降级；
- 自适应模拟器在配置为离线模型时被服务端拒绝；
- 真实多轮对话、tool-call 轨迹与对话证据链未验证。

因此“对话任务完成闭环”是**明确阻塞项**，不能算通过。

## 4. 状态矩阵

| 状态 | 产生方式（实际） | 结果语义 |
| --- | --- | --- |
| `passed` | 文件存在 + JSON 值 + 退出码均满足 | score 1；保留证据 |
| `failed` | 业务预期不满足 | score 0，与执行错误区分 |
| `execution_error` | `sleep 30` 超过 2 秒超时 | 无分数；不是业务失败 |
| `validation_error` / `missing_evidence` | 引用不存在的文件 | score 未知，不判通过、不记 0 |
| `review_required` | 目标已执行，judge 调用失败 | score 未知；目标 stdout 与检查保留 |
| `budget_stopped` | 0 次调用预算下有题需要 judge | 已完成题保留；未启动题不计失败 |
| `skipped` | 预算停止后剩余题目 | 不运行、不评分 |
| `cancelled` | 第一题通过后取消长任务 | 已完成结果保留，部分输出保留 |
| `interrupted` | 运行中 `kill -9` 服务后重启 | 运行及题目标中断，清理状态未知 |
| 清理未知 | 重启恢复 | 显示“服务重启，清理状态未知”，不显示为完成 |
| 未知费用 | 所有批次 | `cost_usd=null`，界面显示“费用未知” |

`review_required` 通过独立回执 [judge-outage.json](evidence/judge-outage.json) 验证；其检查保留 `needs_judge`，错误说明评分调用失败，未改写目标证据。

**清理失败**没有一条可在本机稳定制造的真实失败路径：本地命令的清理是同步进程组回收，Harbor 的清理由 CLI 完成；代码只在重启后报告“未知”。因此“清理失败状态”只验证到“清理状态未知”，没有伪造一个失败事件。这是本轮的明确限制（见 §8）。
