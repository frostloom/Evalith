## 1. 许可结论

| 部分 | 许可 | 对 Evalith 的含义 |
| --- | --- | --- |
| 根仓库除 `/ee/` 外的源码 | MIT Expat | 可 fork、修改、分发；保留版权和许可声明。 |
| `/ee/` | Rhesis Enterprise License | **不能复制、合并、分发、再许可或销售**；生产使用需 Rhesis ToS。必须从 fork/镜像中删除，而不是仅在运行时禁用。 |
| SDK / `packages/rhesis` / Penelope | MIT | 可复用；保留声明。 |
| NOTICE 中的 garak/deepeval/deepteam/OTel/transformers | Apache-2.0 | 保留 NOTICE，标明修改（如有）。 |
| OWASP Top 10 / Agentic AI 材料 | CC BY-SA 4.0 | 保留署名与不背书声明；生成的测试文本是否构成“改编”需法务判断。 |
| psycopg / chardet | LGPL-3.0 / LGPL-2.1 | 动态导入、未修改；提供许可文本和重链接能力，不要求开源 Evalith。 |
| Redis 基础镜像 | 标签相关；7.4+ 为 RSALv2/SSPLv1 | 不要把 `redis:7-alpine` 当作固定 BSD；pin 7.2 或改用 Valkey。 |
| 官方 `ghcr.io/rhesis-ai/*` 镜像 | 含 EE 源码 | **不得重标/分发**；必须自建 EE-free 镜像。 |

## 2. 必须删除/替换（阶段 1 前完成）

1. **删除 `ee/`**：从仓库、镜像和依赖中移除；后端 `--extra ee`、前端 `@rhesis/ee-frontend` 和 `ee_bootstrap` 一起处理。
2. **删除品牌素材**：`apps/frontend/public/logos/`（15 个）、`public/elements/`（24 个）、`public/auth/hero-wash.png` 等；这些文件明确不属于 MIT。
3. **替换硬编码品牌**：`ThemeAwareLogo` 的 wordmark PNG、两处内联 platypus SVG、约 150 处 “Rhesis” 文案/链接（72 个非测试文件）、支持/文档/GitHub/Discord/定价链接。
4. **替换法律文本**：`_imprint.html.jinja2` 的德国 Impressum、Rhesis ToS/隐私链接；不能把 Rhesis 的法律文本当成 Evalith 的。
5. **默认关闭出站连接**：`OTEL_RHESIS_TELEMETRY_ENABLED`（compose 默认 `true`）、`https://telemetry.rhesis.ai`、`ENABLE_RHESIS_KEY`（默认 `true`）、`https://api.rhesis.ai` / Polyphemus 默认。
6. **补齐字体 OFL**：Sora / Sometype Mono / Geist 未随仓库带许可文本；引入时自行附带 OFL 文本。
7. **镜像内放入 LICENSE/NOTICE**：当前 Dockerfile 未复制；MIT/Apache 的分发义务需要满足。

## 3. 品牌替换的可配置边界

`BRAND_*` 只覆盖 favicon、产品名、两种颜色、字体；**不能**清除 wordmark、内联 SVG、文案、外链和法律文本。因此：

- 短期：`BRAND_*` 用于颜色/产品名/favicon；
- 必须做代码替换：Logo 组件、两处内联 SVG、支持/文档/ToS/定价链接、Imprint；
- 不能把“设置了 BRAND_*”当成已完成去品牌化。

## 4. 运行配置中的出站连接

本次运行为了本地验证，使用官方 0.20.1 镜像 + 冻结提交的 2 个差异文件只读挂载，并关闭了遥测；完整源码构建未完成。**上游 compose 默认会外联**。Evalith 的部署模板必须显式：

```yaml
OTEL_RHESIS_TELEMETRY_ENABLED: "false"
ENABLE_RHESIS_KEY: "false"
```

并移除/覆盖 `OTEL_EXPORTER_OTLP_ENDPOINT`、`RHESIS_BASE_URL`、平台密钥相关默认值；在部署文档中说明不会向 Rhesis 发送数据。
