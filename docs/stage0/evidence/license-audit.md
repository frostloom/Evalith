# Evalith stage-0 — Rhesis license / third-party / brand audit

Repo: `<rhesis checkout>` @ `ce24bb1993fc545bb0ccb0d8b3951683ac14fff1` (tag state v0.20.1, `VERSION` = `0.20.1`).
Scope: only the parts Evalith would plausibly reuse (core frontend, core backend, worker/beat, SDK + `packages/rhesis` + Penelope, container images, docs). Every claim below cites `path:line`; quotes are verbatim and short.

## 1. Bottom line

1. **The code Evalith wants is MIT Expat, and the MIT grant is broad** — `LICENSE:8` grants the right "to use, copy, alter, merge, publish, distribute, sublicense, and/or sell copies of the Software". The only code carve-out is `/ee/` (`LICENSE:4`: "Any files located within directories labeled \"/ee/\" (if present) are governed by the license terms specified in the \"ee/LICENSE\" file"). A fork is legally clean if we keep the copyright + permission notice (`LICENSE:9`) and the third-party notices (`NOTICE:1-72`, Apache-2.0 §4 obligations).
2. **`/ee/` must be deleted, not merely disabled.** `ee/LICENSE:37-39` says "it is forbidden to copy, merge, publish, distribute, sublicense, and/or sell the Software", and production use requires a signed Rhesis ToS (`ee/LICENSE:18-24`). Critically, **the stock Docker images deliberately ship EE source** (`apps/backend/Dockerfile:43-47` "Deployed images always carry the EE code"; also `:140-143`; `apps/frontend/Dockerfile:41-43`). Publishing a stock Rhesis image as Evalith's = distributing EE-licensed code. Core itself touches EE in exactly two files (`apps/backend/.../app/ee_bootstrap.py:41-81`, `apps/frontend/src/ee_bootstrap.ts:16-26`), both documented for removal in `apps/frontend/src/ee_bootstrap.ts:16-22`.
3. **Brand is *not* fully removable by config.** `BRAND_*` replaces favicon, product name, two colours and a font (`apps/frontend/src/config/branding.ts:63-76`; `docker-compose.yml:83-88`). It does **not** touch: the hard-coded wordmark PNGs (`apps/frontend/src/components/common/ThemeAwareLogo.tsx:19-22`), ~150 literal "Rhesis" strings across 72 non-test files under `apps/frontend/src`, two inline platypus SVG paths embedded in components (`.../metrics/components/MetricCard.tsx:25`, `.../components/common/SelectMetricsDialog.tsx:48`), or hard-coded `rhesis.ai` / `github.com/rhesis-ai` / `discord.rhesis.ai` links.
4. **Two outbound Rhesis couplings are on by default in the stock compose file** and must be flipped for an independent deployment: product telemetry (`docker-compose.yml:77` `OTEL_RHESIS_TELEMETRY_ENABLED: ... :-true`, endpoint `:146` `https://telemetry.rhesis.ai`) and the Rhesis platform-key mode (`docker-compose.yml:62` `ENABLE_RHESIS_KEY: ... :-true` → default base URL `https://api.rhesis.ai`, `apps/backend/src/rhesis/backend/app/config/settings.py:383`).
5. **No copyleft blocks the reuse**, with two exceptions to manage: the OWASP material is **CC BY-SA 4.0** (`NOTICE:49-60`) and its section text is used to generate tests (`NOTICE:58-60`); and the `redis:7-alpine` base image (`docker-compose.yml:114`) is a moving tag whose 7.4+ releases are no longer BSD. Everything else is MIT / Apache-2.0 / BSD / OFL / PostgreSQL / LGPL-by-dynamic-link.
6. **Verdict:** reuse core under MIT; delete `ee/`, strip brand assets and in-copy strings, replace the legal imprint (`.../email/templates/_imprint.html.jinja2:9-15`) and the Rhesis ToS/privacy links (`apps/frontend/src/components/auth/TermsAcceptanceField.tsx:5-6`), and build EE-free images. Estimate: ~1–2 engineer-days of de-branding, no licensing blocker.

## 4. Unresolved risks

1. **EE residue in images is a live distribution risk.** `apps/backend/Dockerfile:43-47,140-143` and `apps/frontend/Dockerfile:41-43` intentionally bake `ee/` into shipped images, gated only at runtime by `RHESIS_LICENSE` (`ee/backend/src/rhesis/backend/ee/__init__.py:47-65`). If anyone builds with the stock Dockerfiles and pushes to an Evalith registry, that is redistribution of Enterprise-licensed code (`ee/LICENSE:37-39`). Needs: remove `COPY ee/...`, drop the `ee` extra (`apps/backend/pyproject.toml:80,217`), drop `@rhesis/ee-frontend` (`apps/frontend/package.json:48`) and `transpilePackages` (`apps/frontend/next.config.mjs:132`), and no-op `apps/frontend/src/ee_bootstrap.ts` per its own recipe (`:16-22`). **Unverified:** whether `uv.lock` still resolves `rhesis-backend-ee` when the extra is removed — must be re-locked.
2. **Community-mode functional gap is unproven.** With EE absent, only `SSO`, `API_CLIENTS`, `RBAC`, `AUDIT_LOG` (`apps/backend/src/rhesis/backend/app/features/__init__.py:54-59`) disappear, and gates fail closed. But `DefaultLicenseProvider` is *permissive* (`features/__init__.py:103-110`) and only replaced when EE bootstraps; we have not executed a core-only boot to confirm no route assumes a provider was installed. Needs a smoke test (`uv sync` without `--extra ee`, run `community-boundary` job locally: `.github/workflows/backend-test.yml:88-...`).
3. **OWASP CC BY-SA reach is ambiguous.** `NOTICE:58-60` says the reports are "used as context for generating security tests". ShareAlike could be argued to attach to generated test text if it reproduces section wording; the code path is `apps/backend/src/rhesis/backend/app/services/owasp.py:34-43` + `sdk/src/rhesis/sdk/services/owasp_extractor.py:39-41`. Legal review needed before Evalith sells OWASP-derived test sets. Also keep the OWASP non-endorsement sentence somewhere user-visible.
4. **`redis:7-alpine` license is tag-dependent** (`docker-compose.yml:114`). We did not resolve the tag to a digest in this audit; if it resolves to 7.4+, the bundle carries RSALv2/SSPLv1. Pin a known-BSD tag or move to Valkey. Same class of issue: `mirror.gcr.io/nocodb/nocodb:latest` is AGPL but currently unused (`apps/nocodb/Dockerfile:1`).
5. **Font license files are missing upstream.** Only `apps/frontend/public/fonts/be-vietnam-pro/OFL.txt` exists; Sora/Sometype Mono/Geist TTFs ship bare (`apps/frontend/public/fonts/{sora,sometype-mono,geist}/`) though all are OFL-1.1 upstream. We must vendor the OFL texts ourselves — and confirm whether any family carries Reserved Font Names that force a rename after subsetting.
6. **Shipped deployment config disagrees with the code default on telemetry.** `settings.py:184-194` defaults `OTEL_RHESIS_TELEMETRY_ENABLED=False`, but `docker-compose.yml:77` sets `:-true`, `.env.example:163` states "On by default for self-hosted deployments" (with `# OTEL_RHESIS_TELEMETRY_ENABLED=true` at `:165`), and the endpoint is hard-coded to `https://telemetry.rhesis.ai` (`docker-compose.yml:146`). If Evalith reuses the compose file verbatim, **self-hosted installs send usage spans to Rhesis by default** — a data-protection statement we cannot make.
7. **Brand-name strings count is an estimate, not an inventory.** "~150 occurrences across 72 files" comes from `grep -rn "Rhesis" apps/frontend/src --exclude-dir=__tests__ --exclude='*.test.*'`. Some are legitimate references we may keep (e.g. upstream attribution), some are user-visible branding; each needs triage. A complete inventory is a follow-up.
8. **Trademark clearance is out of scope here.** MIT grants copyright rights only; `LICENSE:15-16` explicitly reserves "Logos, trademarks, and other brand assets". Whether "Evalith" itself is clear, and whether any Rhesis *word* mark appears in our UI copy by accident, needs a separate trademark search.
9. **`ThemeAwareLogo` dead-code conclusion is grep-based.** No consumer of `branding.logo` was found (`apps/frontend/src/types/navigation.ts:62` declares it; only `layout.tsx:431` sets it). If a consumer exists that the grep missed (dynamic access, SSR path), the Rhesis wordmark would render — worth one browser check before shipping.
10. **No `LICENSE`/`NOTICE` file is copied into either runtime image** (`apps/backend/Dockerfile` has no `COPY LICENSE|NOTICE`; `apps/frontend/Dockerfile:115-119` copies only build output + `public/`). MIT's "include in all copies" (`LICENSE:9`) and Apache §4(d) are therefore currently unmet for image distribution — must be fixed on our side.
